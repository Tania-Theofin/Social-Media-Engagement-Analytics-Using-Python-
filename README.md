# Social-Media-Engagement-Analytics-Using-Python-

## 📌 Project Overview

Social media platforms generate large amounts of data through likes, comments, shares, impressions, and watch time. Analyzing this data helps understand audience behaviour, measure content performance, and identify engagement trends.

This project focuses on analyzing social media engagement data using Python. It uses data cleaning, manipulation, statistical analysis, and visualization techniques to identify patterns and generate meaningful insights.

## 🎯 Project Objectives

- Analyze social media engagement metrics.

- Identify the best-performing post types and content categories.

- Compare engagement rates across different countries.

- Understand the relationship between age and engagement.

- Compare verified and non-verified accounts.

- Analyze device usage and watch time.

- Study the impact of sentiment on engagement.

- Create static and interactive data visualizations.

## 📂 Dataset Description

Dataset: social_media_engagement_5000.csv

The dataset contains 5,000 social media records with 19 original columns.

🛠️ Technologies and Libraries Used

- Python – Programming language

- Pandas – Data manipulation and analysis

- NumPy – Numerical operations

- Matplotlib – Data visualization

- Seaborn – Statistical visualization

- Plotly – Interactive visualizations

- Jupyter Notebook – Development environment

# Final Insights – Social Media Engagement Analytics

## 1. Content Performance
- Video posts achieved the highest average engagement rate among the post types.
- Food was the best-performing content category, followed by technology and lifestyle.
- Brazil had the highest average engagement rate, followed by Australia and France.

## 2. User Trends
- Age showed almost no linear relationship with engagement rate.
- Verified accounts had a slightly higher average engagement rate than non-verified accounts.

## 3. Behavioral Insights
- The best time of day for impressions could not be determined because the dataset contained posting dates but no exact posting times.
- Mobile users had the highest average watch time compared with desktop and tablet users.

## 4. Sentiment Analysis
- Negative sentiment posts had the highest average engagement rate, followed by neutral and positive posts.
- Negative posts also had slightly higher average impressions and watch time than neutral posts.

## Overall Conclusion
The analysis shows that post type, content category, country, device type, and sentiment can help explain differences in social media engagement. Video posts and food-related content performed particularly well in terms of average engagement rate. Mobile devices showed the highest average watch time, while verified accounts had a slightly higher average engagement rate. Age had almost no linear relationship with engagement rate. These findings can help guide content planning and social media strategy.
